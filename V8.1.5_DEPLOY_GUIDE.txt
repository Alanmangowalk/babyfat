BabyFat V8.1.5 部署說明

這版處理三件事：
1. 預約頁手機底部不再固定顯示「我的預約 / 立即預約」，避免正在填表時誤觸跳頁。
2. 點「打開官方 LINE」前會自動把預約草稿存在瀏覽器；24 小時內回到預約頁會恢復步驟與已填資料。
   預約頁的全站浮動 LINE 客服也暫時隱藏，只保留表單內明確的官方 LINE 按鈕。
3. Google Sheet 後台增加 D1 主動拉取：
   - 手動：BabyFat 系統 > V8.1 同步 D1 訂單回後台
   - 自動：安裝雙向同步後，每 5 分鐘從 D1 補抓一次
   - 可查看：BabyFat 系統 > V8.1 檢查 D1 同步狀態

A. Cloudflare / GitHub
- 不用刪 GitHub 舊檔。

- Commit 到 main。
- 不用重建 D1。
- 不用重跑 migration。
- 不用改 SHEET_SYNC_TOKEN。
- Database ID 已保留：

- 不要建立新的 deployment。
- 原本 /exec URL 不變。

C. 先把目前 D1 測試訂單拉回 Sheet

D. 安裝可靠雙向同步

Google Sheet 是營運管理後台與鏡像。
