BabyFat V8.2.0 多日預約

這版修正「一張預約只能選一天」。

客人端
- 一張訂單可選 1–10 個上課日期。
- 日期可連續，也可不連續。
- 一張訂單只產生 1 個預約編號、1 筆付款。
- 同張訂單的板種、課程、半日/全日、時段套用到全部日期。
- 課程費 = 每日課程費 × 上課天數。
- 住宿、攝影不因課程天數自動重複計價；住宿仍依客人選的晚數與房數。
- 我的預約會一次顯示全部上課日期。

D1
- 新增 booking_days 明細表。
- Worker 會自動 CREATE TABLE IF NOT EXISTS，不必先手動跑 SQL。
- bookings.lesson_date 保留第一個日期，確保舊系統相容。
- 舊訂單沒有 booking_days 時，自動視為 1 天。

Google Sheet
- 「預約訂單」新增最後一欄：全部上課日期。
- 「每日課表」會把多日訂單拆成每天計算。
- 「你好同學媒合」也會按每天拆開顯示。
- 目前「分配教練」仍是整張訂單共用同一位教練；不同日期要不同教練，下一階段應做每日日程/教練排班明細。

部署順序
1. GitHub：解壓 Cloudflare 包，覆蓋 repo 根目錄，Commit main。
2. 等 Cloudflare 部署後，/api/health 應顯示 version 8.2.0。
3. Apps Script：用 GAS 包的 Code.gs 覆蓋，儲存。
4. 管理部署 > 編輯既有 Web App > 新版本 > 部署。不要建立新的 deployment。
5. Google Sheet 重新整理。
6. BabyFat 系統 > V8.2 啟用多日預約後台。
7. BabyFat 系統 > V8 安裝雙向同步。
8. 測試一筆 3 天預約，確認：
   - 官網合計金額 = 單日課程費 × 3 + 加購
   - 我的預約顯示 3 個日期
   - 預約訂單「全部上課日期」有 3 個日期
   - 每日課表出現 3 天

重要
- V8.2.0 不改目前 24H 延時 1 小時的商業規則；它仍沿用訂單層級資格。
- 若多日全日課希望「每一天都送 1 小時」，要另外確認規則後再改。
