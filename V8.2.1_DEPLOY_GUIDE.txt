BabyFat V8.2.1 多選月曆版

這版只修前端日期 UX，不改 D1 結構、不改 GAS、不改 Token。

主要變更
1. 移除 iPhone 原生 date picker +「再加一天」流程。
2. 改成 BabyFat 自己的月曆，可以直接在同一個月曆上複選日期。
3. 再點一次已選日期即可取消。
4. 支援跨月份、連續日期、不連續日期。
5. 單筆最多 10 個上課日。
6. 已選日期用橘色標示，下面同時顯示日期 chips，可直接點 chip 移除。
7. 第一次進官網就會看到 1/2/3 操作說明與多日預約限制。

目前規則（網站會直接顯示）
- 同一張多日訂單的「雪區／雪場、單板或雙板、班別、半日或全日、時段」全部相同。
- 可以：12/23、12/24、12/25 都上全日同一課程。
- 可以：12/23 上課、12/24 休息、12/25 再上同一課程。
- 不能：第一天全日＋第二天半日（俗稱一日半）放在同一張訂單。
- 不能：同張訂單不同天更換板種、班別或雪場。
- 一日半／不同課程需求請分開預約；不確定可走 LINE 客服。

部署
- 只需要更新 GitHub / Cloudflare。
- 不需要更新 GAS。
- 不需要重建 D1。
- 不需要跑 migration。
- 不需要更換任何 Secret / Token。
- 解壓 ZIP 後直接覆蓋 GitHub repo 根目錄並 Commit 到 main。
- 部署完成後 /api/health 應顯示 version 8.2.1。
- iPhone 若仍看到舊介面，先重新整理；檔案已改為 v=8.2.1 避免快取舊 JS/CSS。

建議驗收
1. 一進預約頁，不應自動幫客人選某一天。
2. 點 12/23、12/24、12/25，三天都變橘色。
3. 再點 12/24，12/24 取消。
4. 切到下一個月，前一個月已選日期仍保留。
5. 選超過 10 天應跳提示。
6. 點下一步時沒有選日期應被阻擋。
7. 最後摘要與送出 payload 應包含全部選取日期。
